# เติมมาตรา · Siam Center Law Group

เกมเติมคำภาษาไทยสำหรับเล่นพร้อมกันในห้องเดียว ผู้เล่นเข้าจากลิงก์ห้องด้วยเบราว์เซอร์บนคอมหรือมือถือ

## เปิดเกมบน Windows

ใช้ Node.js 22 ขึ้นไป เปิด PowerShell ในโฟลเดอร์ที่แตก ZIP แล้วรัน

```powershell
$env:ADMIN_PASSWORD = Read-Host 'ตั้งรหัสผ่านหน้าใส่ตัวบท' -MaskInput
node server.mjs
```

เปิด [หน้าหลัก](http://127.0.0.1:4173/) เพื่อสร้างห้อง หรือเปิด [หน้าใส่ตัวบท](http://127.0.0.1:4173/admin) ด้วยรหัสที่เพิ่งตั้ง หากต้องการเปิดห้องบนเครื่องเดียว ให้เปิดลิงก์ในหน้าต่างส่วนตัวอีกหน้าต่างเพื่อเล่นเป็นคนที่สอง

สำหรับเล่นข้ามเครื่องในวง Wi‑Fi เดียวกัน ให้ตั้ง `$env:HOST = '0.0.0.0'` ก่อนเปิดเซิร์ฟเวอร์ เจ้าห้องควรเข้าผ่านที่อยู่ IP ภายในของเครื่องที่รันเกม แล้วคัดลอกลิงก์ห้องจากหน้านั้น เครื่องที่รันเกมต้องเปิดอยู่และเครือข่ายต้องอนุญาตให้เครื่องในวงเดียวกันเชื่อมต่อพอร์ต 4173

## วิธีใช้

1. เลือกตัวบท ชุดตัวอย่าง หรือวางข้อความเอง แล้วกรอกชื่อเจ้าห้องและจำนวนผู้เล่นรวมเจ้าห้อง ระบุชื่อเพื่อนร่วมทีมไว้ล่วงหน้าได้
2. ส่งลิงก์ห้องให้ทีม ผู้เล่นเลือกชื่อที่เตรียมไว้หรือกรอกชื่อ แล้วรอให้เจ้าห้องเริ่มเกม
3. ในโหมดพิมพ์คีย์เวิร์ด ผู้เล่นเห็นสระและวรรณยุกต์ แล้วพิมพ์คำเต็ม ในโหมดเลือกจาก 4 คำ ผู้เล่นลากคำลงช่องว่างหรือแตะคำแล้วแตะช่องว่าง
4. ทุกคนเห็นนับถอยหลังก่อนเปิดข้อ และหมดเวลาตามนาฬิกาเซิร์ฟเวอร์ ผู้เล่นส่งได้คนละครั้ง ผู้ตอบถูกคนแรกได้ 1 คะแนน ระบบแสดงคะแนนและเฉลยเมื่อหมดเวลา
5. ถ้าเปิดโหมดเลือกคำเอง เจ้าห้องเลือกคำและกดแสดงข้อเพื่อเริ่มนับถอยหลัง เจ้าห้องกดข้อถัดไปหรือจบรอบหลังหมดเวลาของข้อนั้น

เปิดเสียงของเครื่องและแตะหน้าห้องอย่างน้อยหนึ่งครั้งเพื่อให้เบราว์เซอร์อนุญาตเสียง

## เพิ่มตัวบท

ที่หน้า **ใส่ตัวบท** ให้เลือกชุดกฎหมายแล้ววางข้อความหรือใช้ไฟล์ UTF‑8 นามสกุล `.txt` หรือ `.md` คั่นมาตราด้วยบรรทัดว่างหรือบรรทัด `---` ชื่อหัวข้อสั้นให้วางไว้บรรทัดแรกเหนือเนื้อหาของมาตรานั้น กด **ดูตัวอย่าง** เพื่อตรวจการแบ่ง แล้วกด **บันทึกและแทนที่** แต่ละมาตราต้องมีคำต่างกันอย่างน้อยสี่คำเพื่อทำตัวเลือก

ชุดตัวอย่างเป็นข้อความสมมติสามข้อ ชุดกฎหมายจริงเริ่มต้นเป็นรายการว่างจนกว่าจะใส่ตัวบท

กำหนดคำที่จะซ่อนโดยใส่ `[[คีย์เวิร์ด]]` ในตัวบท และเลือกตั้งเวลาของมาตรานั้นด้วย `@เวลา 45` ในบรรทัดถัดจากชื่อมาตรา เวลาที่ตั้งเองใช้ได้ตั้งแต่ 5 ถึง 900 วินาที หากเว้นไว้ ระบบคำนวณตามความยาวตัวบทในช่วง 20 ถึง 180 วินาที หน้าดูตัวอย่างแสดงเวลาของแต่ละมาตราให้ตรวจได้ก่อนบันทึก

## การทดสอบและโฮสต์

- `node --test` ครอบคลุมการแบ่งมาตรา การเลือกคำเอง การล็อกหลังตอบผิด การแข่งตอบพร้อมกัน เส้นตายร่วม การสรุปผล และการเพิ่ม/แทนที่/ล้างตัวบท
- รุ่น Node.js ส่งสัญญาณอัปเดตผ่าน WebSocket เก็บตัวบทใน `data/content/` และเก็บห้องในหน่วยความจำ ห้องหายเมื่อรีสตาร์ต
- `node build.mjs` สร้าง Worker สำหรับ ChatGPT Sites ใช้ D1 เก็บตัวบทและสถานะห้อง ผู้เล่นรับการอัปเดตโดยเช็กสถานะทุกประมาณครึ่งวินาที มีการจำกัดอายุห้อง และข้อความวางเองถูกนำออกจากสถานะห้องเมื่อจบรอบ การเผยแพร่ต้องตั้ง `ADMIN_PASSWORD` เป็นค่าลับของเว็บ
