มาตรา 1310 “สร้างโรงเรือนในที่ดินผู้อื่นโดยสุจริต” — สรุปสั้นทบทวน

1️⃣ จุดชี้ขาด = “ความสุจริต”

- ขณะสร้าง ไม่รู้ว่าเป็นที่ดินคนอื่น หรือเชื่อว่ามีสิทธิปลูกสร้าง
- ไม่ตรวจสอบเขตที่ดิน = ประมาทร้ายแรง → ไม่สุจริต (ไป ม.1311)
- ต้องสุจริตตลอดการก่อสร้าง (รู้ภายหลังแล้วยังสร้างต่อ = ไม่สุจริต)

2️⃣ ใช้ได้เฉพาะกรณี “เป็นส่วนควบ”

- ต้องสร้างโดย ไม่มีสิทธิ (ไม่ได้เช่า/ไม่ได้รับอนุญาต)
- ถ้ามีสิทธิตามสัญญา → โรงเรือนไม่เป็นส่วนควบ → ใช้ ม.1310 ไม่ได้ → ต้องรื้อถอนตามสัญญา

3️⃣ การปรับใช้เป็นกฎหมายใกล้เคียง

- ผู้จะซื้อสร้างบ้าน (แต่โอนไม่ได้)
- ผู้ขายฝากสร้างบ้าน (ไถ่ไม่ทัน)
  → ศาลใช้ ม.1310 โดยอนุโลม

4️⃣ สิทธิของเจ้าของที่ดิน (วรรคสอง)

- ถ้าเจ้าของ ไม่ประมาท → บอกปัดไม่รับ และสั่งรื้อถอน
- ถ้ารื้อถอนแพงเกินควร → เรียกให้ผู้สร้างซื้อที่ดินตามราคาตลาดได้

ถ้าต้องการ ผมสามารถทำ ตารางเปรียบเทียบ ม.1310 vs ม.1311 vs ม.146 แบบออกสอบให้ท่องเร็วได้ครับ.

  - ค่าแห่งที่ดินที่เพิ่มขึ้น

มาตรา 1312 “สร้างโรงเรือนรุกล้ำ” — สรุปสั้นทบทวน

1️⃣ ต้องเป็น “โรงเรือน” เท่านั้น (ออกสอบบ่อยสุด)

- ✔️ เป็นโรงเรือน/ส่วนสำคัญของบ้าน (ครัว ชายคา กันสาด ฐานราก) → ใช้ ม.1312
- ❌ ไม่ใช่โรงเรือน (รั้ว กำแพง โรงรถแยก แท็งก์น้ำ แอร์ ท่อ ฯลฯ) → ต้องรื้อถอน

2️⃣ ต้องรุกล้ำ “ส่วนน้อย”

- ตัวบ้านอยู่ในที่ดินตนเป็นหลัก → ใช้ ม.1312
- ถ้าส่วนใหญ่รุกในที่คนอื่น → ไป ม.1310 หรือ ม.1311

3️⃣ ความสุจริต

- ไม่รู้ว่ารุกล้ำขณะสร้าง = สุจริต
- ไม่ตรวจสอบแนวเขต = ไม่สุจริต
- เจ้าของที่ดินข้างเคียงรู้เห็นไม่ทักท้วง → มักถือว่าสุจริต

4️⃣ ใช้กับที่ดินเอกชนเท่านั้น

- รุกล้ำที่ดินรัฐ/สาธารณะ → ต้องรื้อถอนเสมอ

5️⃣ ผลทางกฎหมาย

- สุจริต: ผู้สร้างเป็นเจ้าของส่วนที่รุกล้ำ + เสียค่าใช้ที่ดิน + จดทะเบียนภาระจำยอม
- ไม่สุจริต: เจ้าของที่ดินสั่งรื้อถอนและคืนสภาพได้

จำง่าย:
“โรงเรือน + รุกล้ำน้อย + สุจริต → อยู่ได้ (เสียค่าใช้ที่ดิน)”
“ไม่ใช่โรงเรือน / ไม่สุจริต / รุกล้ำมาก / ที่ดินรัฐ → รื้อถอน”
